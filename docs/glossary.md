# Thuật ngữ
| Thuật ngữ | Định nghĩa |
|---|---|
| Comparison | So sánh điều kiện với biến kiểm soát |
| Adaptation | Thay đổi trạng thái hoặc chiến lược theo kinh nghiệm |
| Model Evolution | Thay đổi model có cơ chế học và bằng chứng; ngoài phạm vi MVP |
| Digest | Định danh nội dung model, khác tên tag có thể thay đổi |
| Quantization | Biểu diễn trọng số ở độ chính xác thấp hơn |
| Run | Một phiên đo có nhiều task/lần lặp; run_id duy nhất |
| Holdout | Tập đánh giá cuối không dùng tạo prompt/memory/feedback |
| TTFT | Thời gian đến token nội dung đầu; chưa đo trong client non-streaming |
| N/A | Không đo được hoặc không áp dụng, khác giá trị 0 |
